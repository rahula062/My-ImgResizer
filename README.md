# Media Hub — Professional Image & PDF Studio

**Media Hub** is a high-performance, 100% client-side web application for processing images and PDF documents directly inside your browser. No file uploads, no server storage, zero privacy risks.

---

## ⚡ Core Features

- **↔️ Image Resizer**: Precise pixel dimensions & aspect ratio lock.
- **✂️ Crop Image**: Custom crop ratios & canvas padding color controls.
- **📦 Image Compression**: Quality slider with real-time compression preview.
- **🔄 Format Conversion**: Batch convert between JPG, PNG, WEBP, GIF, and BMP.
- **🪪 Passport Photo Maker**: Official dimensions for US, UK, EU, India, Canada & print-sheet layout (4x6").
- **📈 Increase File Size (KB)**: Padded byte allocation to meet strict portal minimum file size requirements.
- **🪄 Remove Background**: Color tolerance eyedropper to erase solid/distinct backgrounds instantly.
- **✨ Quality Enhancer**: Sharpening & contrast filter engine.
- **💧 Image Watermark**: Custom text/image watermarks with opacity & positioning.
- **🔄 Rotate & Flip**: 90°/180°/270° rotation & horizontal/vertical mirroring.
- **🎨 Image Filters**: Brightness, contrast, saturation, blur, grayscale, sepia, invert.
- **💎 Round Corners**: Corner radius adjustment & full circular cropping.
- **📝 Text Overlay**: Add text with custom fonts, colors, and shadow effects.
- **📄 Images to PDF**: Convert multiple images into a unified PDF document.
- **🗂️ Merge PDFs**: Combine multiple PDF files into one.
- **🖼️ PDF to Images**: Extract pages as high-resolution PNG/JPG files with ZIP download.
- **🗜️ Compress PDF**: Strip unnecessary metadata and object streams to reduce PDF size.
- **📊 EXIF Viewer**: Inspect image EXIF metadata or strip metadata before sharing.
- **⚡ Batch Processor**: Bulk resize, convert, compress, or rotate dozens of files simultaneously.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Vanilla CSS Design System + Tailwind CSS
- **PDF Engine**: `pdf-lib` & `pdfjs-dist`
- **Archiving**: `JSZip`
